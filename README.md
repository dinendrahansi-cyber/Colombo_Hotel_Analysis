This repository contains a Python data analysis project focused on evaluating the monthly revenue data of leading hotels in Colombo.

### Key Features:
* Data cleaning and pre-processing (handling currency formats and missing data).
* Calculation of statistical metrics such as average monthly revenue.
* Data visualization using Matplotlib and Seaborn to represent hotel performance.

### Tools Used:
* Python (Pandas, Matplotlib, Seaborn)
* Google Colab
